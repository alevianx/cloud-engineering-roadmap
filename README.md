# Cloud Engineering Roadmap → AWS Solutions Architect Associate (SAA-C03)

Ruta de aprendizaje desde fundamentos de redes hasta la certificación de AWS.
Método: videos + estudio con IA + **laboratorios prácticos en AWS (Free Tier)**.

## Fases

| # | Fase | Objetivo |
|---|------|----------|
| 01 | Networking | Entender cómo viaja un paquete: OSI, IP, subnetting, DNS, TLS |
| 02 | Cloud fundamentals | Linux básico y conceptos de cloud |
| 03 | AWS | Servicios principales (cada tema = teoría + lab) |
| 04 | AWS architecture | Diseñar soluciones con el Well-Architected Framework |
| 05 | Terraform & DevOps | Infraestructura como código, Docker, CI/CD |
| 06 | Projects | Aplicar todo en proyectos reales (portafolio) |
| 07 | Exam preparation | Exámenes de práctica y repaso de temas débiles |

## Cómo estudiar cada tema

1. Ver el video del tema.
2. Tomar notas en el `.md` correspondiente (usa la plantilla que ya tiene).
3. Pedirle a la IA que te explique lo que no entendiste y que te haga preguntas (ver `resources/ai-study-prompts.md`).
4. **Hacer el lab en la consola de AWS** (lo práctico es lo que más se fija).
5. Anotar dudas en `07-exam-preparation/weak-topics.md`.

> ⚠️ Antes de empezar con AWS: crea una alerta de presupuesto (AWS Budgets) y activa MFA en la cuenta root.
